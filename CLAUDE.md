# Building Governmint

Governmint (gov.eurth.org) is live: `main` deploys it. It is one of Eurth's worldbuilding tools and stands on their shared shell. The standing instructions:

- **Governmint's own design is kept exactly as it was perfected** (Stijn, 16 November 2026). The suite provides only the header and the footer. Everything between them (the row of actions, the sticky section bar with its icons and progress line, the panels, options, buttons, charts and windows) keeps Governmint's own styles, sizes, corners, weights and colours, as on gov.eurth.org. Never restyle the tool to the suite's rules, and never swap its classes for `eu-` ones. A change to how the tool looks needs Stijn's word first.
- Governmint is exempt from the suite's AAA-contrast and 44px-target checks and is held to WCAG AA with 24px targets: `"eurth": { "axe": { "level": "aa", "targets": 24 } }` in `package.json`, and `scrollLine: false` in `eurth.config.mjs`, since the section bar draws its own line. `src/contrast.test.ts` checks its own colour pairs.
- How that is built: Governmint's styles live in `src/app.css` and in each component, inside the `.gov` wrapper (`src/App.svelte`). Its tokens are declared on `.gov`, because several share a name with the suite's but not a value; `app.css` also undoes the suite's base styles inside the wrapper. Keep Governmint's own windows (`<dialog>`) inside `.gov`, and the suite's (the share dialog) outside it. When something in the tool looks off, compare it with the live site before changing a style.
- Read `node_modules/@eurth/style/HANDBOOK.md` first. On everything else the tools share (stack, the shell, privacy, search, sharing, offline, launch, writing), the handbook wins over any brief; say so if they disagree. Its Shell section carries the same exception for Governmint's design.
- The shell comes from `@eurth/style` and is never rebuilt here: the header, the footer, the theme switch, the share dialog, the question Random asks, toasts and the offline note. The dice beside the name are the suite's `RandomButton`, wearing Governmint's look.
- Nothing is stored: no cookies, localStorage, sessionStorage or IndexedDB. A country lives in its link (`src/model/link.ts`: query string, versioned) and in the nation's profile file. A link made today must open the same country for good: `tests/link.test.ts` holds links from the live site, and they must keep passing. When the settings change shape, raise the version and keep reading the old ones.
- Governmint owns the `government` section of the profile file and leaves every other section untouched (`src/model/profile.ts`).
- The Worker (`worker/`) only counts minted countries behind `/api/*`: one number in one Durable Object. Ask Stijn before giving it anything else to do.
- `eurth.config.mjs` and `@eurth/style/build` are for build time only; never import them from a Svelte component. Hand components what they need as props (`siteUrl`, `host`, `github`).
- Found a gap or a bug in the shell? Don't patch around it here: it is fixed in `@eurth/style`, so every tool gets the fix.
- Done means: the tool still looks and behaves as on the live site, `npm run check`, `build`, `test`, `axe` and `smoke` passing, README, roadmap and feedback log up to date.
- Work on a branch; `main` is the live site. Ask Stijn before spending money, adding any Cloudflare product, or changing another repository.
